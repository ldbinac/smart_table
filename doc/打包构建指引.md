# 打包构建指引

> 打包构建可以本地直接运行的程序，非部署于服务器上的程序。

> 若需要部署于服务器上，建议使用容器化技术（如Docker）进行部署。

## 1. 环境要求

- Python 3.11 +
- Node.js 18.x +
- Redis 7.x +

## 2. 安装依赖

```bash
pip install -r requirements.txt
```

- 安装 Node.js 依赖

```bash
pnpm install
```

## 3. 构建项目

```Shell
# 1. 编辑 version.json
vim version.json
# 将 "version": "1.2.3" 改为 "1.2.4"

# 2. 重新构建（所有产物自动使用新版本）
python build.py windows --skip-frontend
```

## 完整构建

```bash
cd smart-table-spec
python build.py windows  # 构建windows版本
python build.py linux  # 构建linux版本
```

## 前置检查

```bash
cd d:\_dev\fs_table\smart-table-spec
python build.py --clean-only  # 清理后重新测试
python build.py windows --skip-frontend  # 跳过前端，只测试打包
```

## 4. 验证构建

- 检查构建目录（`dist`）
- 确认所有文件都已生成

# docker构建指引
## 1. 环境要求
- Docker 20.10 +
- Docker Compose 2.4 +
- Docker Buildx 0.10 +

## 2. 构建镜像（使用构建脚本）

> SmartTable Docker 一键式构建脚本
> 负责：前端编译、依赖安装、Docker 镜像构建的全流程自动化
> 
> 用法:
>     python build_docker.py                    # 构建镜像（使用已有前端产物或重新构建）
> 
>     python build_docker.py --no-cache         # 不使用 Docker 缓存构建
> 
>     python build_docker.py --skip-frontend    # 跳过前端构建，使用已有 dist
> 
>     python build_docker.py --tag v1.0.0       # 指定镜像标签
> 
>     python build_docker.py --push             # 构建并推送到镜像仓库
> 
>     python build_docker.py --run              # 构建并启动容器


```bash
# 快速构建多平台架构镜像并推送到阿里云仓库
python build_docker.py --tag 1.6.6 --tag latest --registry xxx.cn-heyuan.personal.cr.aliyuncs.com/smart-table --image smarttable
```

## 3. 运行容器
```bash
docker compose up -d
```
