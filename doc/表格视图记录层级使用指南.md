# 表格视图记录层级（树形表格）使用指南

## 概述

记录层级功能允许你在表格中建立父子记录关系，形成树形层级结构。你可以将相关记录组织为层级关系，像目录树一样展开和折叠，方便管理任务分解、分类目录、组织架构等场景。

### 典型使用场景

- **任务分解**：主任务下挂子任务，子任务下继续分解
- **分类目录**：一级分类 → 二级分类 → 三级分类
- **组织架构**：部门 → 小组 → 成员
- **项目规划**：项目 → 阶段 → 任务 → 子任务

---

## 一、开启记录层级

### 方式一：通过视图工具栏开启

1. 进入目标数据表的**表格视图**
2. 点击工具栏上的 **树形** 按钮
3. 在下拉列表中选择一个**关联自身表**的字段作为"父记录字段"
   - 如果列表为空，说明尚未创建关联自身表的字段，可参考方式二先创建字段
4. 选择后，表格自动切换为树形层级展示模式

![工具栏树形按钮示意](https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=SmartTable+toolbar+with+a+tree+icon+button+highlighted+in+blue+next+to+other+toolbar+buttons+like+filter+and+sort+on+a+clean+white+interface&image_size=landscape_16_9)

### 方式二：创建关联自身表的字段

1. 点击表格右上角的 **+** 按钮，选择 **关联** 字段类型
2. 在目标表选择中，选择当前数据表（显示为 `当前表名（当前表）`）
3. 关联类型自动设置为 **一对多**（不可更改）
4. 设置字段名称，例如"父记录"、"上级任务"等
5. 保存字段
6. 回到工具栏，点击 **树形** 按钮，选择刚创建的字段即可

## 二、树形表格基本操作

### 2.1 展开与折叠

- **展开子记录**：点击父记录行左侧的 **▼** 箭头，展开该父记录的所有直接子记录
- **折叠子记录**：点击父记录行左侧的 **▶** 箭头，折叠该父记录下的所有子记录
- 展开/折叠状态仅影响当前视图，关闭后重新打开会恢复为默认展开状态

### 2.2 层级缩进显示

- 每条记录根据其层级深度自动缩进显示
- 每级缩进 20px，最多支持 **4 级**层级嵌套
- 层级越深，缩进越大，视觉上清晰区分父子关系

```
一级记录（缩进 0px）
├── 二级记录（缩进 20px）
│   ├── 三级记录（缩进 40px）
│   │   └── 四级记录（缩进 60px）
│   └── 三级记录（缩进 40px）
└── 二级记录（缩进 20px）
```

### 2.3 添加子记录

**方式一：右键菜单**
1. 右键点击需要添加子记录的记录行
2. 选择 **添加子记录**
3. 系统自动在该记录下方创建一个新的空记录，自动关联为子记录
4. 编辑新记录的各字段值

**方式二：索引列 "+" 按钮**
1. 将鼠标悬停在某条记录左侧的索引列（行号区域）
2. 点击出现的绿色 **+** 按钮
3. 系统自动创建子记录

### 2.4 调整层级关系

**方式一：右键菜单**

- **提升层级**：将当前记录上移一层
  - 例如：记录 A 是记录 B 的子记录，选中"提升层级"后，记录 A 成为记录 B 的兄弟记录
  - 如果记录已经是顶层记录（无父记录），则无法提升

**方式二：拖拽排序**

- 鼠标悬停在行号区域，出现拖拽手柄（`⋮⋮`）
- 按住拖拽手柄上下拖动，即可改变记录顺序
- 拖拽父记录时，其所有子记录会跟随移动

## 三、与筛选功能配合使用

当表格启用了树形层级模式，筛选功能会智能处理父子关系：

- 如果筛选结果包含某条子记录，该子记录的所有父级记录也会一并显示，确保能看到完整的层级上下文
- 例如：搜索"任务C"，如果"任务C"是"任务B"的子记录，则"任务B"也会显示在结果中

---

## 四、删除记录时的行为

### 删除父记录
- 父记录被删除，但其**子记录不会删除**
- 子记录的父记录字段值会被清空，成为顶部（顶层）记录
- 你可以手动重新关联这些子记录到新的父记录

### 删除子记录
- 子记录被删除，同时**级联删除**其所有后代记录（子记录的子记录）
- 如果只想删除当前记录但不影响后代，建议先通过"提升层级"操作将后代记录提升到同级

## 五、常见问题

### Q1: 为什么工具栏上看不到"树形"按钮？
确保当前视图是**表格视图**，且你有该表的编辑权限。如果使用的是其他视图类型（如看板视图、日历视图），记录层级功能暂不支持。

### Q2: 为什么"父记录字段"列表是空的？
需要先创建一个关联自身表的 LINK 类型字段。请参考"方式二：创建关联自身表的字段"。

### Q3: 最多支持多少级层级？
最多支持 **4 级**层级嵌套，超过 4 级的子记录会被截断显示。

### Q4: 删除父记录后，子记录会怎样？
子记录不会丢失，但父记录字段会被清空，子记录变为顶层记录。你可以手动重新建立关联。

### Q5: 如何关闭树形层级模式？
在工具栏点击 **树形** 按钮，选择下拉列表中的清空选项（或再次点击已选中的字段），即可关闭树形展示，恢复为普通平铺列表。

### Q6: 拖拽排序在树形模式下如何工作？
拖拽父记录时，该父记录的所有子记录会跟随移动。如果拖拽到其他记录下方，可以改变记录的层级归属。

---

## 六、技术说明

记录层级功能基于现有的 **关联字段** 类型实现，通过将关联目标指向当前数据表自身（单向关联，一对多）来建立父子记录关系。该功能在 VTable 引擎的树形渲染能力基础上实现，支持 Canvas 高性能渲染。
