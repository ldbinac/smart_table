# SmartTable 1.6.2：表格之间的数据，终于可以自动串起来了

做表格的时候，最烦的往往不是录入数据，而是数据分散在好几张表里，想看个完整信息得来回切换、复制粘贴。比如客户表里有客户ID，订单表里有客户ID，想知道这个订单是哪个客户的，就得自己查。项目表里有负责人ID，人员表里有联系方式，想发个通知又得切出去找。

SmartTable 1.6.2 这次就是来解决这些琐碎麻烦的。我们把几个呼声很高的功能一起端上来了。

## 一、查找字段：一张表看到多张表的内容

这次最核心的更新，是查找字段（Lookup Field）正式可用。

它的作用很直接：你可以在某个表里引用另一个表的数据。比如在订单表里直接显示客户名称，在项目表里直接显示负责人的手机号。设置一次之后，数据会自动跟着关联关系显示出来，不用手动复制，也不用担心两边不一致。

记录抽屉和详情页也做了适配，打开一条记录时，关联过来的信息会一起展示，看数据的时候更连贯。之前默认值的显示和格式化也顺手修了一波，引用过来的数据现在能正确渲染。

## 二、工作流引擎：到点就自动跑

工作流在 1.6.2 里继续扩展，新增了三种能力：

- **记录时间触发器**：支持「到达记录中的时间时」触发，适合预约提醒、合同到期、项目截止这类基于时间点的场景。
- **查找记录节点**：工作流执行过程中可以查询关联数据，比如触发后根据某个字段值找到对应的记录再做处理。
- **发送邮件节点**：工作流跑完之后可以直接发邮件通知，比如任务分配、状态变更、到期提醒。

这几个节点加上之前的能力，基本能把很多重复性的操作串成自动流程。比如合同到期自动发邮件提醒负责人，同时把相关记录标红。

## 三、公式字段：写公式不再靠猜

公式字段在这个版本也更好用了。

首先是新增了公式助手组件，集成在字段配置对话框里。以前写公式可能得对着文档慢慢试，现在组件会辅助你完成，门槛低了挺多。其次是支持了更多字段类型的计算结果格式化，日期处理也新增了相关能力，显示效果做了优化。

举个例子，你可以直接写一个公式算出某个日期距离今天有多少天，或者把几个数字字段汇总成一个总价，结果会按你期望的格式显示出来。

## 四、仪表盘分享：做好的看板可以发给更多人看

仪表盘做完之后，以前可能只能自己看，或者截图发出去。现在这个版本支持把仪表盘以链接形式分享给其他人，对方点开就能看到。

分享的时候可以设置标题和备注，方便说明这个仪表盘是干什么的。访问密码只在创建分享时返回一次，后续不会反复出现在接口里，分享链路相对更安全一些。

这个功能适合周报、项目进展、数据监控这类需要定期给团队或客户同步的场景。

## 五、总结一下

1.6.2 没有搞什么大场面，就是把几个日常用起来最顺手的功能做扎实了。如果你之前被跨表数据、手动通知、重复计算这些问题困扰过，这个版本值得试试。

更新到 1.6.2，数据自己串起来，你少操点心。

## 六、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似 Airtable 或飞书多维表格。

### 核心特性

- **26 种字段类型**：文本、数字、日期、单选、多选、成员、附件、查找、公式、关联……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **43 个内置公式函数**：数学、文本、日期、逻辑、统计、查找、关联……基本能想到的公式都有了
- **实时协作**：多人同时编辑表格，实时同步数据
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR……
- **仪表盘系统**：KPI 卡片、图表、实时数据展示
- **文档管理**：富文本、Markdown语法支持、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可一键启动，无需复杂配置
- **Docker 一键部署**：内嵌 Redis
- **双数据库支持**：支持 SQLite（轻量数据库，无需配置启动可用） 和 PostgreSQL（生产环境可用功能和性能更强大的PG数据库，切换配置即可使用）
- **自动化工作流**：当某个条件满足时（或到达某个时间点时），自动执行一系列操作（V1.6版本新增）

### 快速体验

#### 方式一：一键启动包，下载解压即可使用

下载 release 包解压后双击 start.bat 即可一键启动

#### 方式二：Docker 一键启动

下载 Docker 镜像 `ygbinac/smarttable:latest` 即可一键启动

```bash
docker run -d -p 80:80 ygbinac/smarttable:latest
```
