# 开源多维表格SmartTable v1.6.11 —— 签字能直接签了，框选一片就能算账，导入也更听话

***

> **一句话总结**：这版主要干了这几件：✍️ **签名字段**——手写、输入都能签，表格、表单里直接落款；📊 **拖拽框选实时统计**——鼠标一拖，选中那一片的合计、均值当场算给你看；📥 **导入更聪明**——顺序导入严格按 Excel 里的行顺序来，Excel 建表时还能自动推断数字、货币、百分比的精度；另外把**关联字段、时区、Alembic 迁移**这些老大难又收拾了一遍。做审批、做台账、做统计的朋友，这版能省不少事。

***

## 一、这版最大的变化是啥？

上一版（1.6.10）把评论 @人、表单二维码、用户名登录这些协作能力铺开了，性能和安全也加固了一圈。1.6.11 这版看着没那么"大开大合"，但都是平时高频用得上的实在东西——签字终于能直接在表里签了，选一片单元格就能看合计均值，导入数据不再乱序、精度也不用手动一个一个调，顺手还把关联字段、时区、迁移检测这些老坑又填了一轮。

- **签名字段**：手写或输入签字，表格、表单、记录抽屉、表单分享页都能用。
- **拖拽框选实时统计**：选中一片单元格，数值列的合计、均值实时显示。
- **导入体验增强**：顺序导入严格按 Excel 的行顺序来；Excel 建表自动推断数字 / 货币 / 百分比字段的精度。
- **国际化与迁移**：更新 i18n 文案和工作流节点验证提示路径；修了 Alembic 多版本、多 head 场景下的迁移判定。
- **一批稳定性修复**：编辑保存失败回滚、时区统一、关联字段显示与同步、导入模板问题等。

下面分开唠。

***

## 二、签名字段：手写、输入都能签 ⭐

这块是这版的头牌，给所有拿表格走审批、做签收、搞确认的朋友准备的。

以前想在表里留个签字，基本得绕路——要么传张手写图片当附件，要么线签完再录进系统，麻烦不说，还容易对不上。这版直接加了**签名字段**：想手写就用鼠标或手指在画板上签，想省事就直接输入名字，签完落进表里，跟其他字段一样能看能筛。

而且它不是只在表格视图里能用——**表单、记录详情/新增抽屉、对外分享的表单页**都支持。比如你发个表单让人确认收货，对方打开就能直接签，不用先注册账号、不用装啥插件。

> 🖼️ \[截图位置：签名字段手写画板与输入签字]

另外图标也顺手改了：从容易跟"编辑"图标混淆的样子，换成了指针样式。小细节，但天天盯着的表格，看起来清爽点也是好的。

## 三、拖拽框选实时统计：选中一片，账立刻算出来 ⭐

做台账、对数据的朋友对这个需求肯定不陌生：想看看某一列数加起来多少、平均多少，以前要么建个公式列，要么把数据复制出来丢进 Excel 里算——就为了看一眼，折腾半天。

这版给表格视图加了**拖拽框选实时统计**：在单元格区域上按住鼠标一拖，选中那一片，数值列的**合计和均值**当场就显示出来，手一松就能接着干活。临时核个数、扫一眼趋势，不用再建列也不用再复制粘贴。

> 🖼️ \[截图位置：拖拽框选单元格实时显示合计与均值]

说白了就是把"算一下"这件事，从三步缩到一步。

## 四、导入体验增强：顺序导入 + 精度自动推断

导入这块这版加了两样东西，都是"用过才觉得早该有"的那种。

- **顺序导入模式**：以前导入数据，顺序有时候跟 Excel 里排的未必一模一样。这版加了顺序导入模式，勾上就能限定导入的数据**严格按照 Excel 里数据的顺序**来。对那些讲究先来后到的场景——比如按顺序发号、按排期落库——这点挺关键。
- **Excel 字段精度自动推断**：用 Excel 导入建表时，系统现在会看列里的数据，自动推断这列该是**数字、货币还是百分比**，连精度一起定好。以前导完还得手动改字段类型、调小数位，现在多数情况下导进来就是对的。

## 五、国际化与迁移：细节也在打磨

这版还有两件"不上台面但挺重要"的活儿：

- **国际化**：更新了一批 i18n 文案，还有**工作流节点验证提示的路径**也梳理了一遍。用英文界面、或者在工作流里配节点的朋友，提示信息会更准、路径也更清楚。
- **Alembic 迁移判定修复**：修了两个跟升级检测有关的坑——一个是**多版本 Alembic 升级判定永远为 True**（等于"该不该升都判成该升"），另一个是**多 head 场景下迁移检测逻辑错误**。用大白话说：以前升级检测有时候判不准，现在判准了，跨版本升级心里更有底。

这块看着不起眼，但真赶上从老版本往上跨的时候，能省掉不少"为什么没升级 / 为什么又重复升级"的疑惑。

## 六、修了哪些 Bug？

这版修的老坑也不少，挑重点说：

- **编辑保存失败不再"闷声"**：以前保存失败了，原因不显示、表格视图里单元格的值也不回退，人还以为存上了。现在失败会把**接口返回的原因**显示出来，单元格值也**回滚**回去，不至于稀里糊涂。
- **时区统一了**：统一了时区处理，解决时间**序列化和解析时的偏差**。跨时区的团队、或者时间看着莫名差几小时的情况，这版能好不少。
- **双向关联导出能重新导入了**：以前双向关联导出后，显示名重复，导致导出的文件没法再导回来。这版修了。
- **关联字段显示正常了**：修了关联字段显示成**裸记录 ID**、以及**反向关联显示名缺失**的问题——现在看到的是正经名字，不是一串 ID。
- **复制 / 批量创建不再显示"关联 N 条"**：以前复制记录或批量创建时，关联字段没跟着同步，列表里会冒出个"关联 N 条"的怪提示，这版修好了。
- **导入模板两处小问题**：模板**遗漏主字段**、以及**日期时间字段的示例格式写错**，都改了。

***

## 七、升级提醒（重点！）

这版不像 1.6.10 那样动了外键约束和大的迁移逻辑，升级相对省心，但几点还是留意下：

1. **正常启动就行**：签名字段属于新字段类型，涉及的库表变更走 Alembic 自动迁移，正常启动即可，别手动去建表改字段。
2. **老规矩，先备份**：虽然这版改动没那么大，有重要数据的库还是建议升级前手动备一份，留条退路总没错。
3. **跨版本升级更稳了**：这版修了 Alembic 多版本判定和多 head 检测的 bug，从老版本跨上来的时候，升级检测会比以前准，少踩"判不准"的坑。
4. **Docker 用户拉新镜像**：直接用最新镜像升级，别用老镜像。
5. **环境变量照旧配齐**：生产环境把 `SECRET_KEY` / `JWT_SECRET_KEY` 设好，这事儿从 1.6.10 强调到现在，别再图省事跳过。

## 八、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **27 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找、地理位置……基本能想到的字段都有（这版又添了签字字段）
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **70+ 个内置公式函数**：数学（支持运算符）、文本、日期、逻辑、统计、跨表引用
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **插件扩展体系**：前后端都能写插件，附官方示例，想加啥功能自己来
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 -e JWT_SECRET_KEY=改成你的自己的key值 -e SECRET_KEY=改成你的自己的key值 ygbinac/smarttable:latest
```
