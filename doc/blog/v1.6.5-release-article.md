# 开源多维表格SmartTable v1.6.5 —— 全英文界面上线，第三方应用也能接进来了

***

> **一句话总结**：这版主要干了这几件：🌐 **全英文界面**（系统里几乎所有界面都翻成英文了，还会跟着系统语言自动切）；🔌 **第三方应用能接入了**，开放 OAuth2 接口，外挂系统能光明正大跟 SmartTable 打通；🔍 **应用审计日志**，谁用接口干了啥一目了然；📅 **日期输入、公式显示**这些细节也顺手打磨了一遍；外加一堆 bug 给修掉了。

***

## 一、这版最大的变化是啥？

前面几个版本在猛冲功能广度——主从表、树形层级、站内信、工作流脚本……功能堆得挺厚了。v1.6.5 就没急着再加大功能，而是回头把**几个一直悬着的"地基问题"**补齐：

- **语言**：之前一直只有中文，海外同事或者英文系统环境下用着别扭。这版把界面整套翻成英文，还能自动跟着系统语言切。
- **开放能力**：光自己用不过瘾，很多朋友想把 SmartTable 接进自己的业务系统。这版把 OAuth2 接口和开放 API 正式放出来了。
- **安全可溯**：接口放开了，总得知道是谁在调、干了啥。配套加了应用审计日志。
- **细节体验**：日期怎么填、公式怎么显示、导出能带啥……这些平时用着硌手的地方，挨个顺了。

下面分开唠。

***

## 二、全英文界面：终于能切语言了

这次最大的"体感"变化，是**整个系统支持多语言了**。

### 以前啥情况？

SmartTable 一直只有中文界面。你要是给海外团队用，或者服务器装英文系统上，满屏中文，人家看着一头雾水。之前也有人自己在本地改文案凑合用，但一升级就全没了，白改。

### 现在咋用？

右上角多了个**语言切换**的地方，手动点一下就能在中文 / 英文之间切。更省心的是——它**会自动检测你系统的语言**。你系统本身是英文的，打开 SmartTable 默认就是英文，不用你动手。

> 🖼️ \[截图位置：语言切换组件与系统语言自动检测]

这次翻译覆盖的面挺广，基本把常用界面都包了：

- **认证页**（登录、注册那套）
- **表格、文档**相关界面
- **仪表盘**组件
- **工作流**配置界面
- **视图**（顺带把视图的名称和描述也支持国际化了——你给视图起的名字，英文用户看的是英文版）
- **成员 / 用户管理**
- **反馈、分享、系统设置**这些

还有个细节：**模板预览**也支持英文了，并且新增了一批英文模板。你分享出去给老外填表，人家打开直接是英文表单，不用再纠结。

另外英文文案也整体过了一遍——字段类型、组件名称那些英文说法统一了，不会这块叫 Field 那块叫 Column 之类的前后不一。

> 🖼️ \[截图位置：英文界面下的表格视图与模板预览]

说白了，这版是把"多语言"这件从框架层面就立起来了，后面加新功能也会顺带着出英文，不用再像以前那样补丁式地补翻译。

## 三、第三方应用接入：你的系统能跟 SmartTable 打通了

这是给**开发者 / 想做集成的朋友**准备的大招。

### 以前啥情况？

SmartTable 之前基本是个"孤岛"——功能都在自己里头，你想让自己写的系统去读它的数据、或者反过来往里塞数据，要么走账号密码硬怼，要么自己扒接口，既不正规也不安全。

### 现在咋用？

这版正式放出了**第三方应用接入能力**，走的是标准的 **OAuth2** 那套：

- 你在后台注册一个"第三方应用"，拿到对应的鉴权信息
- 你的系统走 OAuth2 流程授权之后，就能用**开放 API** 去调 SmartTable 的数据了
- 不用再拿用户账号去硬登录，权限边界清晰，哪边出问题一查就知道

> 🖼️ \[截图位置：第三方应用注册与 OAuth2 授权流程]

还配套写了**应用接入文档**，把接入流程、怎么调接口、有哪些示例都写清楚了。第一次接的朋友照着文档走就行，不用盲猜。

> 🖼️ \[截图位置：应用接入文档页面]

### 关键操作都有记录：应用审计日志

接口放开了，安全这根弦就得绷紧。这版加了**应用审计日志**——哪个第三方应用、在啥时候、干了啥操作，全给它记下来。

你说这有啥用？举个实在的例子：哪天发现数据被人乱改了，翻一下审计日志，立刻能看出是哪家的应用、什么时间动的手。出了问题能溯源，比瞎猜强一百倍。

## 四、日期和字段：几个顺手的小优化

### 统一日期输入组件 DateInput

以前不同地方填日期，输入框长得还不太一样，有的还不支持你想要的格式。这版做了个**统一的 DateInput 日期输入组件**，全站填日期都用它，而且**支持自定义日期格式**——你想要 `YYYY-MM-DD` 还是 `2026年08月19日` 那种，按你的习惯来。

> 🖼️ \[截图位置：DateInput 日期组件与自定义格式]

### 公式字段能按文本显示了

公式算出来的结果，以前展示方式比较固定。这版让公式字段**支持以文本格式显示**——有些场景下你就是想让它原样当字符串看（比如算出来的是编号、是带前导零的编码），现在能直接这么展示，不会被当成数字给吞掉前导零。

### 数值字段展示统一了

数字字段的展示格式做了统一处理，不同视图、不同地方看同一个数字，长得一致了，不会出现这张表显示 `1,234` 那张表显示 `1234` 的尴尬。

## 五、表格和导出：该补的都补上

### 历史变更审计弹窗

想知道一条记录是谁改的、改了啥？这版加了**表格历史变更审计弹窗**，点开就能看到这条记录的变更轨迹。配合上面说的审计能力，数据出了问题有地方查。

> 🖼️ \[截图位置：表格历史变更审计弹窗]

### 导出更实用了

导出的时候，现在能**带上成员的真实姓名**，还有**公式字段的计算结果**。以前导出可能只给你个成员 ID、公式只给个公式本身，拿到 Excel 里还得自己再算一遍、自己再翻人是谁。现在一步到位。

### 链接字段编辑器更新

关联 / 链接字段的编辑器重做了一遍，选关联记录、填关联值的时候手感更顺，不容易点错。

### 分享表单支持公式字段

你把表单分享出去收数据的时候，现在表单里**能展示公式字段**，而且支持**提交过滤**——比如某些公式算出来不符合条件的，提交时就能拦下来。收上来的数据更干净。

## 六、账户与表单体验

- **修改密码弹窗**：以前改密码可能得绕到设置里找半天，现在直接弹窗就能改，顺手。
- **表单匿名 / 登录提交**：分享出去的表单，既能让匿名用户直接填，也能在需要登录的场景下走登录提交——两种玩法都支持了，按你分享的用途自己选。
- **版本号展示**：反馈弹窗底部现在会显示当前版本号。以后你提 bug 的时候，顺手截个带版本号的图，作者一眼就知道你用的是哪版，定位快多了。

***

## 七、修了哪些 Bug？

这版修的 bug 也不少，挑重点说：

- **分组视图 + 主从表**：修复了在分组视图下配置主从表会导致数据看不见的问题（这个挺坑，配置好了却一片空白）
- **字段编辑状态残留**：修复了关掉编辑框之后，某些编辑状态还赖着不走的情况
- **开关单元格**：修掉了新增行里开关单元格显示不对、以及多人同时保存时的锁冲突问题
- **PostgreSQL 兼容**：统一了 UUID 列的类型，用 PostgreSQL 的朋友不会再被类型对不上卡住
- **迁移脚本幂等**：迁移脚本加了幂等检查，老库结构有点偏移的，升级时不会再因为重复执行而报错
- **仪表盘删除**：修了仪表盘删除相关的问题
- **分享表单富文本**：修了分享表单里富文本长度校验不对的问题
- **打包上传目录**：修了打包模式下自定义上传目录不生效的问题

***

## 八、升级提醒

几个点留意下：

1. **数据库会自动升级**：这版涉及的结构变更走 Alembic 自动迁移，正常启动就行，不用手改表
2. **PostgreSQL 用户**：UUID 列类型统一了，升级时迁移脚本会自动处理，正常启动即可
3. **想接第三方应用**：去后台注册应用、看接入文档，照着 OAuth2 流程走
4. **英文界面**：升级后第一次打开建议**强刷一下页面**（Ctrl + F5），让新的语言资源加载上

## 九、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **26 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **43+ 个内置公式函数**：数学、文本、日期、逻辑、统计
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **站内信通知**：不依赖邮件也能收到消息
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
