# 开源多维表格SmartTable v1.6.7 —— 插件扩展点全落地，站内信也能写进工作流了

***

> **一句话总结**：这版主要干了这几件：🔌 **插件系统扩展点全落地**——之前 1.6.6 把插件地基打了，这版把扩展点和能力全铺开，还配了多套示例插件和工具脚本，插件管理页也放开给所有人了；🔔 **通知更猛了**——工作流里能直接发站内信，铃铛也更听话；🔍 **查找 / 关联字段更好挑数据**了，能跟当前记录比、能按选择项和文本过滤；🌳 **树形视图**叶子能筛能排，几个烦人的交互 bug 也修掉了；外加 PDF 预览跨域、依赖打架、复制视图、关联字段导出等一批问题搞定。

***

## 一、这版最大的变化是啥？

上版本（1.6.6）把**插件体系**的地基给打好了——前后端能写插件、有 hello-panel 示例、能挂扩展点了。但说实话，那会儿扩展点还没铺全，插件管理页也还藏着。1.6.7 就是接着把这条路走通、走顺：

- **插件系统补完**：扩展点全落地，能力全开，还多了好几套示例插件和配套的工具脚本，二次开发直接照抄就行；插件管理页也对所有登录用户开放了。
- **通知能力增强**：工作流里能直接发**站内信**了，铃铛通知的交互和状态也更稳。
- **查找 / 关联字段更好用**：挑关联数据更聪明——能跟当前记录比、能按选择项 / 文本过滤，数值和日期聚合也顺了。
- **树形视图打磨**：叶子节点能筛选排序了，之前几个交互上的坑（搜索丢结果、"+"按钮错位）也填了。
- **稳定性**：文档编辑、复制视图、关联字段导出、公式字段转换、PDF 预览跨域……一批实际用着别扭的问题修掉了。

下面分开唠。

***

## 二、插件系统：扩展点全落地，人人都能装了

这是这版跟 1.6.6 衔接得最紧的一块。1.6.6 把"能不能写插件"这个问题解决了，1.6.7 解决的是"写起来方不方便、能不能放开用"。

### 以前啥情况？

1.6.6 虽然能写插件了，但扩展点还没铺全，很多想挂的地方还挂不进去；插件管理页权限也收得比较紧，你想装个插件还得折腾权限。说白了，地基有了，楼还没盖几层。

### 现在咋用？

- **扩展点全落地**：插件系统把之前留着的扩展点和能力全部补齐了，想往系统里挂功能，挂哪儿基本都能挂了，扩展能力这下是真的"全"了。
- **多套示例插件 + 工具脚本**：这次不是只给你一个 hello-panel 了，配套甩出**多套示例插件**和**扩展点工具脚本**。想接哪个扩展点，先翻对应示例，代码结构、怎么注册、怎么跑，现成参考，二次开发不用从零摸。
- **插件管理页放开**：管理页现在**面向所有登录用户开放**了——看已装的插件，把已有的插件安装到自己创建的多维表格，登录就能干（为了安全，插件的安装还是需要找管理员先安装并启用之后才能普通用户使用）。
- **错误也讲人话了**：插件报错信息统一做了国际化处理，报出来的错不再是看不懂的英文串，中文环境下直接看中文提示。

> 🖼️ \[截图位置：插件管理页面（对所有登录用户开放）]

> 🖼️ \[截图位置：多套示例插件列表 / 扩展点工具脚本]

说白了，这版是把"插件这条路"从能走，变成**好走、人人都能走**。后面社区里要是冒出好玩的插件，装上就能用，不用等官方排期。

## 三、通知能力增强：站内信进了工作流，铃铛也更听话了

通知这块 1.6.4 就上线了站内信系统，这版是把它**接进工作流**、再顺手把交互打磨了一遍。

### 工作流里能直接发站内信了

以前工作流要通知人，基本靠发邮件。现在工作流里多了个**站内信通知节点**——流程走到这一步，直接往相关人员信箱里塞一条站内信，不用再依赖邮件通道，系统里就能收到、就能看。

> 🖼️ \[截图位置：工作流配置里的站内信通知节点]

### 铃铛通知更稳了

铃铛那块的交互和状态管理重做了一遍，点开、已读未读、红点计数这些更跟手，不会因为状态乱了导致该提醒的没提醒、不该亮的还亮着。

### 样式不再串台

之前站内信里要是带了 HTML，偶尔会"串台"——把别的样式带进来污染了页面；详情抽屉的样式作用域也有点问题。这版把站内信 HTML 做了清理、防样式污染，详情抽屉的样式作用域也修正了，页面干净多了。

***

## 四、查找与关联字段：挑数据更聪明了

用关联 / 查找字段的朋友，这版有几个实打实的提升。

### 能跟"当前记录"比了

查找字段现在支持**关联记录比较过滤**——简单说，你挑关联数据的时候，可以拿它跟当前这条记录去比。比如"只显示跟我这条记录负责人相同的关联记录"，这种以前得手工筛，现在直接在过滤里配，挑出来就是干净的。

> 🖼️ \[截图位置：查找字段关联记录比较过滤配置]

### 选择项和文本也能参与过滤

以前查找字段过滤主要看关联本身，这版支持**选择类字段**（单选、多选那些）和**文本字段**的过滤匹配。想按某个下拉选项、或者按关键字去筛关联数据，直接配，不用绕。

### 数值 / 日期聚合更顺，关联数据批量拉

- **聚合转换优化**：数值和日期的聚合转换（求和、平均、按日期归组那些）处理更顺了。
- **关联数据批量获取**：现在会**批量拉取**关联数据，而且加载时显示**树形加载状态**——数据多的时候你能明显看出"还在加载中"，不会以为卡死了干等。

> 🖼️ \[截图位置：关联数据批量加载时的树形 loading 状态]

## 五、树形视图：叶子能筛能排，几个烦人 bug 也修了

树形视图（1.6.4 那版上线的父子层级能力）这版做了增强，主要是让"叶子节点"更好用，顺手修了几个交互坑。

### 叶子节点能筛选、能排序了

树形视图现在支持**叶子节点筛选排序**，并且把分组给禁用了（树形本来就是层级结构，再分组反而乱）。你要是只想看最底层的那些记录、或者想按某个字段给叶子排个序，现在直接来。

> 🖼️ \[截图位置：树形视图叶子节点筛选排序]

### 两个交互 bug 修掉了

- **搜索结果丢失**：之前在树形里搜完、或者表格重建一下，搜出来的结果就莫名没了。这版修好了，搜完踏踏实实在那儿。
- **"+" 按钮错位**：树形视图里那个加号按钮，一滚动就跑偏的问题，也修掉了，加行的时候按钮稳稳在它该在的地方。

***

## 六、部署与依赖：稳一点，快一点

这块是给**运维 / 部署**的朋友准备的，平时感知不强，但真踩到就是大坑。

- **PDF 预览跨域修好了**：之前 PDF 在线预览会被跨域拦截，点开白屏或者加载不出来。这版把跨域拦截的问题解决了，预览恢复正常。
- **依赖打架解决了**：psycopg 降到 3.2.13、eventlet 升了一版，这俩之前有兼容冲突，会莫名其妙出问题。现在版本对齐了，冲突消了。
- **Docker 更顺**：相关的文档和配置样例修正了一遍，Docker 镜像构建和部署配置也优化过，照着样例搭不容易踩坑。
- **压测脚本**：新增大数据量的压测脚本。你要上量、想提前摸一下性能水位，直接拿脚本跑，不用自己从零写。

> 🖼️ \[截图位置：PDF 在线预览正常显示]

## 七、修了哪些 Bug？

这版修复了几个比较典型的问题，

- **文档编辑者没法编辑**：修了文档编辑者打不开 / 没法编辑文档的问题——之前分给人家编辑权限却编辑不了，憋屈。
- **文档标题工具栏设成字符串报错**：文档标题工具栏如果设成一个字符串，会生成样式异常。这版修掉了，设成字符串也不会再把页面样式搞乱。
- **复制视图功能报错**：复制视图这个功能之前点下去会出错，修好了，复制视图正常跑。
- **数字转公式字段报错**：把数字字段改成公式字段会报错，这版修掉，转换能正常走。
- **关联字段导出只给 ID**：导出的时候关联字段只显示记录 ID 不显示名字，拿到 Excel 里一脸懵。这版修成导出显示名称了，对人友好多了。

***

## 八、升级提醒

几个点留意下：

1. **数据库会自动升级**：这版涉及的结构变更走 Alembic 自动迁移，正常启动就行，不用手改表。
2. **依赖变更**：psycopg 降到 3.2.13、eventlet 升了一版，如果你是手动维护依赖的，留意下这俩版本变化，避免冲突。
3. **PDF 预览**：之前被跨域卡住的朋友，这版升级后预览应该就正常了。
4. **想玩插件**：扩展点全落地 + 多套示例，从示例插件和工具脚本入手照着抄最快。

## 九、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **27 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找、地理位置……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **43+ 个内置公式函数**：数学、文本、日期、逻辑、统计
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **插件扩展体系**：前后端都能写插件，附官方示例，想加啥功能自己来
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
