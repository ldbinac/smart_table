# 开源多维表格SmartTable v1.6.6 —— 插件体系上线，你的表格能装"外挂"了

***

> **一句话总结**：这版主要干了这几件：🧩 **插件扩展体系正式上线**，前后端都能写插件，还附带了能照着抄的示例插件；📍 **新增地理位置字段**，地址不再是一串文字，能落到地图上了；📝 **表单大升级**——字段能设默认值和只读了、一行放几个字段你说了算、字段顺序随便调；⚙️ **工作流和仪表盘**也加了料；外加修了一大批 bug，PostgreSQL 迁移失败这个老大难也解决了。

***

## 一、这版最大的变化是啥？

v1.6.5 把多语言和第三方应用接入这两块"地基"补齐了，v1.6.6 就开始往上盖楼——**开放性**是这版的关键词：

- **插件体系**：以前想给 SmartTable 加个自己的小功能，只能改源码，一升级就被覆盖。这版把插件扩展体系立起来了，你的功能可以做成插件"挂"进系统，升级也不怕丢。
- **地理位置字段**：字段类型家族又添一员，地址、坐标、门店位置这些信息终于能"看得见摸得着"了。
- **表单能力**：收集数据是高频场景，这版把表单的"可配置程度"拉高了一大截——默认值、只读、布局、顺序都能自己调。
- **稳定性**：修了一批实际使用中反馈的问题，PostgreSQL 升级迁移失败这个被吐槽最多的也顺手解决了。

下面分开唠。

## 二、插件体系：表格能装"外挂"了

这是这版的**头牌功能**，给所有想深度定制的朋友准备的。

### 以前啥情况？

SmartTable 功能再全，也不可能覆盖所有人的需求。你想加个自定义面板、接个内部系统、或者在表格里塞个自己的小工具，以前只有一条路——改源码。改完还得自己维护分支，官方一升级你就得重新合并，累不说还容易冲突。

### 现在咋用？

这版实现了完整的**插件开发扩展体系**：

- **前后端都能扩展**：不只前端能加界面组件，后端也能写插件逻辑，前后端配合着玩
- **官方示例照着抄**：附带了两个示例插件（前端 + 后端各一个），代码结构、怎么注册、怎么跑，全都有现成参考，不至于对着文档两眼一抹黑
- **表格数据能传给插件**：你在表格里**勾选的记录数据，可以直接传给插件**处理——比如选中几行记录，让插件帮你批量做点什么
- **扩展点可控**：插件能出现在系统的哪些位置（扩展点）是可以约束的，不会到处乱冒，界面干干净净

## 三、地理位置字段：地址能上地图了

字段类型家族又添一员——**地理位置字段**。

### 以前啥情况？

记录门店地址、项目地点、客户位置这些信息，以前只能填个文本字段。"北京市朝阳区幸福路 12 号"看着是一串字，到要用的时候还得自己复制出去搜地图，跟数据完全脱节。

### 现在咋用？

新增的地理位置字段支持**地图选点和坐标存储**，配置里还接入了**天地图服务**。你可以在地图上直接选位置，也可以填地址，记录里存的是结构化的位置数据。

另外它还支持**子格式配置**——你想要"省市区 + 详细地址"还是"经纬度坐标"，按业务场景自己挑。

> 🖼️ \[截图位置：地理位置字段编辑与地图选点]

实际用起来最爽的场景：门店台账、外勤打卡记录、设备巡检点位……这些表配上地理位置字段，信息量直接上一个档次。

## 四、表单大升级：收集数据的体验顺多了

表单（表单视图 + 分享表单）这次一口气加了四个好东西，都是收集数据场景下的刚需。

### 字段默认值和只读，能按字段设置了

分享表单现在支持**字段级默认值与只读配置**。举个实在的例子：你发个周报收集表单，可以把"提交人"字段设成默认值（或者只读，强制就是某个值），填表的人只需要填正文，别的都不用动。收上来的数据格式也整齐。

> 🖼️ \[截图位置：分享表单字段默认值与只读配置]

### 一行放几个字段，你说了算

字段多的表单，以前全是一列排到底，拉半天才能填完。现在**表单视图和分享表单都支持配置每行字段数**——简短的字段并排放一行，长文本独占一行，表单紧凑又好看。填表的人体验直接不一样。

> 🖼️ \[截图位置：表单每行字段数布局配置与效果对比]

### 字段顺序随便调

分享表单支持**调整字段顺序**了，而且表单里可见字段会**按你配置的顺序展示**。哪些字段在前、哪些在后，完全按你的填写逻辑来，不用再迁就字段在表里的创建顺序。

### 关联字段也能进表单了

这个可能是最实用的：**新增记录时支持关联字段的直接选择与写入**。以前填表单遇到"关联记录"只能干瞪眼，现在直接在表单里选。而且**匿名分享表单也支持关联字段读取**——你对外发的收集表，填表人也能正常看到和选择关联数据了。

> 🖼️ \[截图位置：表单中关联字段选择]

## 七、管理与账户

- **平台入口域名**：系统配置里可以设置**平台入口域名**了。邮件通知、站内信里以前硬编码的域名都改成读这个配置——部署在内网、走自定义域名的朋友，收到的通知链接终于是对的了。

## 八、修了哪些 Bug？

这版修的 bug 不少，挑重点说：

- **PostgreSQL 迁移失败**：修了升级到新版本时 PostgreSQL 数据库迁移报错的问题。顺手把 PostgreSQL 驱动切换成了 psycopg，兼容 Python 3.14——之前升级卡住的朋友，这版能过了
- **文档保存**：修了文档保存时乐观锁基准过期与权限校验报错的问题，多人协作文档保存更稳了
- **全文搜索中文**：修了未指定字段时全文搜索中文匹配失败的问题
- **编辑器冲突**：修了长文本和富文本编辑器的按键及剪贴板冲突，复制粘贴不再打架
- **默认值清除**：修了字段默认值设了就删不掉的问题
- **主从表**：修了主从表场景下的记录处理问题，以及新增行后打开详情窗口（放大镜）渲染成关联表字段的问题
- **修改密码**：修了修改密码接口路径错误导致请求不成功的问题
- **幽灵在线**：给在线状态加了**心跳与过期清理机制**，不会再出现人都下线了还显示在线的"幽灵用户"
- **分享表单布局**：修了多列布局下验证码和提交按钮被压缩的问题
- **审计日志**：移除了记录历史的外键级联删除，删关联记录时**审计日志保留完整**，追溯有据
- **表格全局搜索失败**：修复表格在变动之后，全局搜索失败问题和关联字段存在时候无法搜索问题
- 其他：测试邮件返回值错误、无 tableId 路由时插件上下文缺失等也一并修了

## 九、升级提醒

几个点留意下：

1. **数据库会自动升级**：这版涉及的结构变更走 Alembic 自动迁移，正常启动就行，不用手改表
2. **PostgreSQL 用户**：这版专门修了迁移失败的问题，驱动也换成了 psycopg（兼容 Python 3.14），之前升级报错的朋友放心升
3. **用地理位置字段**：需要在配置里填入天地图的服务配置（Key 需自行申请），配置好才能正常使用地图能力
4. **想开发插件**：从插件开发指南和 hello-panel 示例入手，照着抄最快

## 十、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **27 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找、地理位置……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **43+ 个内置公式函数**：数学、文本、日期、逻辑、统计
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **插件扩展体系**：前后端都能写插件，附官方示例，想加啥功能自己来
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
