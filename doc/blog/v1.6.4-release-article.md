# 开源多维表格SmartTable v1.6.4 —— 主从表来了，表格能"套娃"了

***

> **一句话总结**：这版干了四件正事：**主从表（子表）终于支持了**，一条记录点开就能看到挂在下面的明细；**表格能做树形层级了**，任务能一层层拆；**站内信通知上线**，消息不用再靠邮件；**工作流能写 Python 脚本了**，复杂逻辑自己写。另外还把多人同时编辑抢单元格的问题给治了。

***

## 一、这次版本最大的变化是啥？

前面几个版本一直在补功能广度——视图、公式、工作流、仪表盘。这次 v1.6.4 走的是**"深度"路线**：让数据之间能真正"套起来"。

以前你在 SmartTable 里建表，表和表之间靠关联字段连着，但看数据的时候还是各看各的——看订单要开订单表，看订单明细还得再跳到明细表去筛。这次的主从表和树形层级，就是把这个"跳来跳去"的事给解决了。

主要变化分五块：

- **🔗 主从表与树形层级**：一条记录点开直接看明细，记录之间能建父子关系
- **📬 站内信通知**：系统消息直接站内推，不再依赖邮箱
- **🔄 工作流脚本节点**：支持写 Python 脚本，复杂逻辑不用等官方出节点
- **🤝 协同编辑**：单元格加锁 + 冲突检测，多人编辑不打架
- **🔐 权限收敛**：字段和管理类操作收紧到管理员，防误操作

下面挨个说。

***

## 二、主从表：一条记录点开，明细全在里面

这是这次最大的亮点，也是被催得最多的功能。

### 以前是怎么用的？

假设你在管订单。订单表一条记录是一个订单，订单明细表里放着这个订单买了哪些商品。两张表用关联字段连着。

想看某个订单买了啥？流程是这样的：在订单表找到这条记录 → 看关联字段里那几个蓝色标签 → 点进去 → 跳到明细表 → 一条条看。想加一条明细？再跳回去，新建记录，再手动关联回订单。

累。

### 现在是怎么用的？

点开订单记录的详情抽屉，**明细直接以表格形式显示在里面**。要加明细？抽屉里直接点"添加"，关联关系自动建好，不用手动挂。

具体做了这些：

- **子表工具栏**：如果一张主表挂了好几个关联字段（比如订单既有"商品明细"又有"物流记录"），工具栏上可以直接切换看哪个，不用来回找
- **添加关联**：在子表里直接新建记录，或者从已有记录里挑一条挂上来
- **刷新**：子表数据单独刷新，不用刷整个页面
- **二级子表详情**：子表里的记录也能再点开看详情弹窗——相当于能"套两层"

> 🖼️ \[截图位置：详情抽屉内的子表展示与工具栏]

### 什么场景用得上？

- **订单 → 订单明细**：一个订单挂 N 个商品行
- **项目 → 项目成员**：点开项目看参与人员和分工
- **客户 → 跟进记录**：点开客户直接看历次沟通，不用跳表
- **设备 → 维修记录**：资产台账里点开设备，维修历史一目了然
- **课程 → 学员名单**：报名表和课程表挂钩

顺带把抽屉宽度的计算逻辑也优化了，加了个最小宽度兜底——以前某些情况下抽屉会被挤得特别窄，子表根本看不清，现在不会了。

## 三、树形层级：任务终于能一层层往下拆

主从表解决的是"**两张表**之间的关系"，树形层级解决的是"**同一张表内部**记录之间的关系"。

### 怎么用？

先在表里建一个**关联到自己这张表**的字段（比如叫"父任务"），然后在视图设置里把它指定为父字段。搞定之后，表格就变成树形的了——前面带展开箭头，点一下展开子记录，再点一下收起来。

有几个细节做到位了：

- **新增子记录**：右键菜单里直接"新建子记录"，父子关系自动建好
- **升级 / 降级**：右键就能把一条记录往上提一级或者往下降一级，调整层级不用去改字段
- **自动排除自己**：选父记录的时候，列表里不会出现当前这条记录——不然自己当自己的爹，就成死循环了

> 🖼️ \[截图位置：树形表格展开效果与右键菜单]

### 什么场景用得上？

- **任务分解**：大任务 → 子任务 → 子子任务，WBS 那一套
- **组织架构**：公司 → 部门 → 小组 → 人
- **分类目录**：商品一级类目 → 二级类目 → 三级类目
- **项目规划**：项目 → 阶段 → 里程碑 → 具体活儿

想细看操作步骤的，可以翻文档里的《表格视图记录层级使用指南》，那篇写得更细。

## 四、站内信通知：消息不用再等邮件了

以前系统里的消息全靠邮件发。问题是——很多人压根不配 SMTP，配了也可能进垃圾箱，内网环境更是直接发不出去。结果就是：别人把表分享给你了，你不知道；审批流转到你这了，你也不知道。

这次上了**完整的站内信系统**。

- 右上角有通知入口，有新消息直接标出来
- 有专门的通知页面，历史消息都能翻
- **策略改成"站内信优先"**：先站内推，邮件配了就照样发一份，没配也不影响你收到消息
- 覆盖了注册、改密码、分享协作、审批这些场景

对内网部署的用户来说，这个提升挺明显的——终于不用为了收个通知去折腾邮件服务器了。

> 🖼️ \[截图位置：通知中心与消息列表]

## 五、工作流：能自己写 Python 脚本了

工作流的节点再多，也总有覆盖不到的场景。以前遇到官方没提供的逻辑，只能干等，或者绕一大圈用 Webhook 甩给外部系统处理。

这次加了**自定义脚本节点**，支持写 **Python** 脚本。

- 前端有专门的配置面板，**内置代码编辑器**，还能**直接点"测试运行"**看结果，不用整个流程跑一遍才知道对不对
- 后端跑脚本走的是**独立沙箱**，用子进程隔离执行——脚本写崩了不会把主服务带下水
- 流程上下文的数据能拿到，处理完再丢回流程里继续走

### 什么场景用得上？

- 算一些公式函数搞不定的复杂逻辑
- 数据格式清洗转换（比如把一堆乱七八糟的地址串拆成省市区）
- 调第三方接口，把返回结果加工成自己要的格式
- 按自定义规则做数据校验

## 六、多人协作：单元格加锁，编辑不打架

多人同时编辑一张表，最烦的就是——你正改着某个格子，同事那边也在改，最后谁的改动生效全看运气，有时候还直接把人家刚填的覆盖了。

这次把协同这块重做了一遍：

- **单元格锁**：有人正在编辑某个格子，其他人能看到这格被占了，避免同时改
- **锁超时和断线重试**：万一有人开着编辑框就去吃饭了，或者网断了，锁不会一直卡着不放，会自动超时释放
- **冲突检测**：真出现冲突了会弹框告诉你，让你自己决定用谁的版本，而不是默默覆盖
- **自动释放**：页面关掉、组件卸载的时候，手上的锁全部自动放掉，不会留下"幽灵锁"

文档那边也加了**乐观锁**——两个人同时编辑同一篇文档，后保存的那个会收到提示，不会无声无息把前面的内容冲掉。

***

## 七、字段与公式：正则校验和日期函数

### 单行文本能做正则校验了

以前单行文本字段是"你填啥就是啥"，手机号填 11 位还是 13 位、身份证填对没填对，全靠人自觉。

现在可以给单行文本字段**配正则校验规则**了：

- 自己写正则，也能配套写一条校验失败的提示语
- **内置了常用预设**：国内手机号、邮政编码、身份证、IPv4，选一下直接填进去，不用自己憋正则
- **失焦即校验**：填完跳到下一个格子就提示，不用等到提交才报错

填表收集数据的场景特别有用——比如做个报名表分享出去，手机号格式不对当场就拦下来了。

### 公式的日期函数更能打了

日期解析这块重构了。以前有些格式识别不了，现在支持得更全：

- `YYYYMMDD` 这种纯数字的日期
- 毫秒时间戳字符串
- 其他一些常见日期写法

**多层嵌套**的场景也补齐了，比如从身份证号里截出生日再算年龄这种套娃写法，现在能正常跑。

另外公式报错的提示也改了——以前报错就一句"公式错误"，你都不知道错哪了。现在会**告诉你是哪个函数、传了什么参数、具体啥错**。

## 八、权限收紧：防止普通成员误操作

这次把**字段类和管理类操作的权限门槛提高了**：原来"编辑者及以上"能干的事，现在要"管理员及以上"。

涉及工作流、数据表、文档、仪表盘这些管理动作。

为啥要改？因为之前有用户反馈，普通编辑成员一不小心把字段删了、把字段类型改了，一整列数据就没了。编辑数据和管理表结构，本来就应该是两个权限级别的事。

**注意**：如果你团队里有成员之前是"编辑者"角色，还需要管理表结构，升级后记得把他调成管理员。

另外表单分享的限流也调了——以前按客户端 IP 算，同一个局域网里几十号人填表，很容易被误判成刷接口给拦了。现在改成**按分享令牌算**，阈值 100 次 / 15 分钟，正常填表不会再被拦。

***

## 九、其他体验优化

- **表格不再跳回第一行**：以前改完一条数据，表格一刷新就滚回顶部，你还得重新翻下去找刚才那行。现在会自动定位到刚改的那条记录
- **增量更新**：实时更新的时候，行数没变就只更新变的部分，不整个重建，大表格明显更顺
- **右键菜单优化**：菜单项加了悬浮提示，新增了升级 / 降级 / 新建子级的图标，排版也重新理了一遍
- **复制链接更靠谱**：分享链接的复制做了兼容处理，优先用新的剪贴板 API，不行就自动降级用老方案，实在还不行就把完整链接显示出来让你手动复制（HTTP 环境下浏览器会禁用剪贴板 API，之前这种情况直接复制失败）

***

## 十、修了哪些 Bug？

- **下拉选择**：修复了单选/多选编辑器选中值匹配错乱的问题，现在按 id 匹配（老数据按 name 匹配的照样兼容）；顺带修了选项显示文本不对的问题
- **单元格选项**：修复了在单元格里改单选/多选，存进去的值和弹窗里显示的对不上的问题
- **视图校验**：修复了表单视图没法设成默认视图的问题（路由里 table_id 类型对不上导致校验挂了）
- **树形表格**：修复了展开箭头不显示的问题
- **表格滚动**：修复了数据更新后跳回首行
- **分享接口**：统一了前后端的分享接口路径，合并了更新和删除接口，报错提示也改清楚了；修复了后端返回秒级时间戳前端解析不对的问题
- **表单分享**：修复了部分场景下分享链接复制不了的问题
- **公式**：修复了日期/时间字段值在公式比较时类型对不上的问题
- **一键包**：修复了打包模式下会**弹出两个浏览器窗口**的问题（Flask 调试重载器把 run.py 跑了两遍）

## 十一、升级提醒

几个需要留意的点：

1. **数据库会自动升级**：这版加了通知表，走 Alembic 自动迁移，正常启动就行，不用手动改表
2. **前端本地数据库升级到 v10**：升级后第一次打开建议**强刷一下页面**（Ctrl + F5）
3. **权限有变化**：字段和管理类操作提到了管理员，团队里如果有编辑者需要管表结构，记得调整角色
4. **老数据都兼容**：主从表、树形层级都是新增能力，不开就跟以前一样用，不影响存量数据

## 十二、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **26 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **43+ 个内置公式函数**：数学、文本、日期、逻辑、统计
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **站内信通知**：不依赖邮件也能收到消息
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
