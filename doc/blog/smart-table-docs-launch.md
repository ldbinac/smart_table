## 一、先认识一下 SmartTable 是谁

SmartTable 是一款基于 **Vue 3 + Flask** 构建的开源智能多维表格系统，定位类似 Airtable 或飞书多维表格，但它的灵魂在"开源 + 可私有化"：

- 前端：Vue 3 + TypeScript + Vite + Pinia + Element Plus
- 后端：Flask + SQLAlchemy + Alembic
- 数据库：SQLite（默认）/ PostgreSQL（生产推荐）
- 实时通信：WebSocket（Socket.IO），可选启用
- 开源协议：**MIT**——可以放心用在公司里，甚至做商业化改造，没有后顾之忧

它围绕四个维度提供能力：**数据管理 + 视图呈现 + 流程自动化 + 团队协作**。一个 **Base（多维表格）** 就是一个独立工作空间，里面可以有多张数据表、仪表盘、文档和工作流，表与表之间还能通过关联字段建立关系。

### 2. 用户指南：从会用到用得好（最厚实的部分）

**快速开始 / 表格操作**——新人十分钟上手，不用培训。

**七种视图，同一份数据换种看法就换种用法：**

| 视图 | 能干嘛 |
| --- | --- |
| 表格视图 | 经典表格，支持虚拟滚动、列冻结、字段筛选，万级数据首屏秒级渲染 |
| 分组视图 | 按字段分组，最多 3 级分组 + 分组统计 |
| 看板视图 | 卡片拖拽排序与分组，最适合走流程 |
| 日历视图 | 按日期分组，月/周/日切换 |
| **甘特图** | 项目进度时间线，支持任务依赖和拖拽调整（项目管理利器） |
| 表单视图 | 公开分享收集数据，自定义配置 |
| 画廊视图 | 图片卡片网格，适合媒体内容 |

**主从表 & 树表格（层级表）**——处理"一对多""上下级"这类结构数据时，不用再手动拼表。主从表支持子表独立刷新、多关联字段切换；树表格基于自关联的 LINK 字段建立父子关系，最多 4 级嵌套，删父留子、删子级联后代。

**站内信通知**——系统消息、审批提醒直接进站内信，5 种来源标签、4 种状态，消息必达，不用再守着邮件。

**工作流自动化**——可视化设计器，触发器支持定时 / 记录创建 / 记录更新；节点覆盖创建记录、更新记录、查找记录、发邮件、Webhook、条件分支、循环，外加**自定义 Python 脚本节点**。还支持工作流版本快照，可历史回溯。

**字段类型**——关联、查找、公式三大"关系型"本领单独成章，这是它和纯电子表格拉开差距的地方：

- **关联（Link）**：支持一对一 / 一对多 / 多对一 / 多对多，双向关联
- **查找（Lookup）**：跨表查询，8 种聚合方式（求和/平均/最大/最小/计数…）
- **公式字段**：47 个内置函数，覆盖数学、文本、日期、逻辑、统计

**场景实践——直接抄作业：** 项目管理、研发缺陷管理、CRM 客户关系、人事招聘、内容日历。

## 四、为什么值得现在去看看

1. **MIT 许可证**——商业闭源部署无合规风险，这是很多同类开源项目（如 AGPL 系）给不了的安心。
2. **甘特图 + 多级分组视图**——项目管理场景开箱即用，不用装插件。
3. **协同锁 + 站内信系统**——企业协作"消息必达"场景更强，告别"邮件漏看"。
4. **业务字段丰富**（进度/评分/条码/按钮）——配置成本低，少写代码。
5. **可视化工作流编排**——非开发者也能搭自动化，Python 脚本节点给进阶留了口子。
6. **现代前端栈**（Vue 3）——二次开发体验好，社区接手门槛低。

一句话：SmartTable 在"企业协作闭环（锁 + 站内信 + 工作流）"和"开箱即用视图（甘特 / 分组）"上更贴合国内企业场景，且 MIT 更友好；文档站的上线，等于把这扇门彻底打开了。
