## 一、这版最大的变化是啥？

上一版（1.6.7）把插件体系铺开了、通知和查找关联也打磨了一轮。1.6.8 回头把**公式**这个"老地基"好好加了一层楼——之前公式能算，但运算符得手敲、跨表引用不方便、条件统计得绕。这版把这些一次性补上了：

- **公式引擎**：加减乘除括号齐了，跨表整列引用打通，条件统计和兜错函数也补齐。
- **Excel 导入**：关联字段自动认、成员按名字解析，导数据少踩坑。
- **筛选与分组**：成员、关联记录这些字段也能筛了，关联/查找字段能分组，日期时间字段也进了筛选。
- **数据表文件夹**：表一多就乱？现在能建文件夹分组了。
- **仪表盘**：编辑和预览分两个模式，调样式的时候不会误触。
- **成员管理**：加人不用敲邮箱了，搜名字或邮箱就能加，重复添加还有提醒。
- **稳定性**：文档重复点击卡 loading、仪表盘分享标题、公式数字类型报错、SQLite 迁移报错这些烦人问题修掉了。

## 二、公式引擎：写公式终于不用憋屈了

这块是这版的头牌，给所有爱用公式算账、做统计的朋友准备的。

### 以前啥情况？

之前公式也能用，但有俩憋屈点：一是运算符得自己手敲符号，公式助手（FormulaHelper）里没有现成的"加减乘除"给你点；二是想引用别的表的数据，得绕来绕去，没法痛快地拿一整列来算。条件统计（比如"数一下满足条件的有几条"）也得自己拼，麻烦。

### 现在咋用？

- **五种运算符到齐了**：新增加法、减法、乘法、除法和括号（`+ - * /` 和括号），而且公式助手里会**按分类展示**——数学类下头直接能找到，写公式不用再对着符号发呆。
- **跨表整列引用**：现在支持 `[表名].[字段名]` 这种写法，直接把**别的表的一整列**拉过来算。比如你有一张"订单表"和一张"产品表"，想算订单里引用产品的单价合计，直接跨表引用就完事，不用一条条搬。
- **条件统计函数**：新增 `COUNTIF`、`SUMIF`、`AVERAGEIF`、`FILTER` 这几个。举个实在的——`SUMIF` 可以按条件求和（"把状态是已发货的订单金额加起来"），`COUNTIF` 数满足条件的条数，`FILTER` 先筛出一批再交给别的算，统计活儿省一大截。
- **兜底不报错**：新增 `IFERROR`、`NA`、`ERROR` 三个逻辑函数。`IFERROR` 最实用——公式算崩了（比如除零）不再是满屏 `#ERROR`，可以指定一个兜底值，比如 `IFERROR({金额}/{数量}, 0)` 出错就显示 0；`NA()` 返回 N/A 标记；`ERROR("提示语")` 还能主动抛个错带信息。

## 三、Excel 导入：关联和成员不用手填了

把 Excel 数据导进 SmartTable，这版省了两道手工活。

- **关联字段自动匹配**：导入的时候，系统会**自动认出关联字段**并帮你匹配，不用自己一个个去映射对应关系。表头对得上的，基本一键就完。
- **成员按名字解析**：以前导成员字段，得先搞清楚成员 ID 才行。现在**填成员的真实姓名**就能落库成成员字段——你 Excel 里写的是"张三"，导进来就是那个张三，不用再查 ID。

> 🖼️ \[截图位置：Excel 导入关联字段自动匹配 / 成员姓名解析]

这对从别的系统搬家、或者平时拿 Excel 收数据的朋友，能省不少对字段的功夫。

## 四、筛选与分组：挑数据更顺手

筛选和分组这版也加了料，主要是把之前够不着的地方补上。

- **成员、关联记录能筛了**：之前这些字段筛选不太方便，这版成员、关联记录等字段都支持筛选了。比如"只看负责人是张三的记录""只看关联了某客户的"，直接点筛选就出来。
- **关联和查找字段能分组**：关联字段、查找字段现在也能**按分组**展示了，长列表一下子有了结构，不再是一长条刷到底。
- **日期时间也能筛**：日期筛选逻辑增强，除了日期，**日期时间字段**也支持筛选了。精确到时分秒的范围过滤也能玩。

## 十、修了哪些 Bug？

挑重点说：

- **文档卡 loading**：修了重复点击文档导致 loading 状态一直转、复位不了的问题——之前手快多点两下文档就转圈圈停不下来，现在正常了。
- **仪表盘分享标题国际化**：修了仪表盘分享出去时标题国际化显示不对的问题，分享链接里的标题现在跟语言走。
- **公式数字类型报错**：修了公式里"字符串形式的数字"参与运算时类型不对、直接算崩的问题——比如字段里存的是文本"123"，拿来加减乘除现在能正常当数字算了，不会再莫名其妙报错。
- **SQLite 迁移报错**：修了在 SQLite 环境下重放迁移链时，因为部分表没在迁移脚本里定义而报 `NoSuchTableError` 的问题——用 SQLite 部署的朋友，迁移不会再因为这个崩。

## 十一、升级提醒

几个点留意下：

1. **数据库会自动升级**：这版涉及的迁移走 Alembic 自动迁移，正常启动就行，不用手改表。
2. **SQLite 用户**：之前迁移链报 NoSuchTableError 的朋友，这版升级后能正常重放迁移了。
3. **想玩公式跨表 / 条件统计**：升级后去公式助手看看新加的运算符和函数，按分类就能找到；公式里文本格式的数字也能正常参与运算了。
4. **多表管理**：表一多记得用新出的数据表文件夹归类，省得后面乱。
5. **加成员更省事**：后台加人改用成员选择器，搜名字或邮箱就能加，重复添加会有提醒，别再手敲邮箱了。

## 十二、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **27 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找、地理位置……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **70+ 个内置公式函数**：数学（支持运算符）、文本、日期、逻辑、统计、跨表引用
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **插件扩展体系**：前后端都能写插件，附官方示例，想加啥功能自己来
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
