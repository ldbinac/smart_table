# 开源多维表格SmartTable v1.6.3 —— 工作流能"循环"了，公式更全更完善

***

> **一句话总结**：这版搞了三件大事：**工作流终于能循环处理数据了**；**公式函数的"前后端"打通了**；**前端构建换成了 pnpm**。另外还把登录 Token 续期、问题反馈这些长期被吐槽的小痛点给治了。

***

## 一、这次版本最大的变化是啥？

如果说 v1.6.0、v1.6.1、v1.6.2 是给 SmartTable "添砖加瓦"，那 v1.6.3 就像是给它**做了一次"功能整合 + 内功修复"**。它没有大刀阔斧地搞新界面，但每一处改动都踩在实际工作里会遇到的痛点上。

主要变化分四块：

- **🔄 工作流引擎**：循环节点、循环 Webhook、投递日志、画布连线、节点重构
- **🧮 公式与字段**：前后端函数打通、数字字段格式化、关联字段体验优化
- **🛠️ 平台能力**：Token 自动续期、问题反馈入口、附件单击预览
- **📦 工程与构建**：前端构建迁移 pnpm、数据库改 Alembic 迁移

下面挨个说。

***

## 二、工作流功能加强：能"循环"操作数据了

这是这次最大的亮点。以前 SmartTable 的工作流只能**线性执行**——A 节点完了到 B 节点，B 完了到 C 节点。如果你想对一组数据**逐条处理**（比如：给一个部门的所有成员挨个发邮件），就只能在外层用代码包一层。

现在有了**循环节点**，工作流本身就能干这事。

### 循环节点

在画布上多了个"循环"节点。把一个数组（比如"所有待处理订单"）丢进去，节点内部会**对每一条数据挨个执行一遍子流程**。执行完一条再执行下一条。

> 🖼️ \[截图位置：循环节点配置与画布展示]

### 循环体 Webhook

循环节点里面的子流程，也能对外发 Webhook 了。比如循环处理订单时，每处理一笔都推一个 Webhook 出去，外部系统能实时收到通知。

> 🖼️ \[截图位置：循环节点内 Webhook 触发效果]

### Webhook 投递日志

以前 Webhook 发出去了，发没发成功、对方收没收到，只能靠猜。现在加了**投递日志查看**功能，每次投递都有记录——成功失败、重试次数、响应内容都能看。

> 🖼️ \[截图位置：Webhook 投递日志列表]

### Webhook 变量提示

配 Webhook 的时候，经常要写一堆变量名拼来拼去。现在鼠标**悬停在变量上**就能看到变量说明、示例值，不用再去翻文档了。

> 🖼️ \[截图位置：Webhook 变量悬停提示]

### 画布连线小升级

画布上的连线现在**带方向箭头**了，流程的执行方向一眼就能看清。编辑模式下"添加节点"按钮临时隐藏，视觉上更干净。

> 🖼️ \[截图位置：画布连线方向箭头效果]

### 节点类型重构

工作流节点类型做了**细粒度枚举化重构**，老的流程数据全部兼容，不会出岔子。

### 修了一堆 Workflow 的 Bug

- 修复了**流程节点空结果处理**和**空节点校验**的逻辑
- 修复了**内联 Webhook 投递和重投递拦截**的问题
- 修复了**时区获取逻辑**，支持读取浏览器本地时区（之前在海外出差用时区不对很烦）

## 三、表格字段功能优化与完善

### 数字字段
这次把数字字段的默认值规则优化了，终于不再永远默认为0了，而是根据字段默认值设置自动判断默认写0还是写空值，避免有些场景下默认值为0会导致业务问题。


### 公式字段
这次把**前后端的公式函数注册统一了**——你说一个函数能用，前后端都认。

具体修整包括：

- **MID 文本函数** —— 截取字符串中间某一段的函数
- **DATEDIF 函数** —— 计算两个日期之间间隔的函数，支持更多单位（年/月/日/时/分/秒等）
- **公式函数统一** —— 前后端共用一套函数注册表
- 还有其他…………

### 关联字段

关联字段（"查找"字段）以前偶尔会出现**缓存不刷新、显示错位**的问题。这次把缓存逻辑和显示策略都重整了一遍，体验更稳。


### 列宽自动缓存

表格查看的时候，发现某个字段内容较多，手动拉宽了一点查看数据，现在可以**列宽缓存**了，下次同一台电脑，再次打开同个表格，终于不用重新拉宽查看数据了，会自动恢复到上次的列宽设置。

## 四、平台能力：把长期吐槽的几个痛点治了

### 🕐 Token 自动续期

以前用 SmartTable 写大表格，写了俩小时结果一刷新，**"登录已过期，请重新登录"**——相信我，那种心情你不会想体验。

这次搞了**完整的 Token 自动续期体系**：在 Token 即将过期前自动续上，你根本感觉不到它的存在。


### 📮 问题反馈入口

以前遇到问题，要么得去 GitHub 提 Issue，要么得翻文档找联系方式。现在系统全局右上角里**直接加了"问题反馈"入口**，一键提交问题、附上截图和日志，作者能直接看到。


### 🖼️ 附件图片单击预览

以前看附件里的图片，得先下载下来再用看图软件打开。现在**直接单击缩略图**就能在页面里看完整图片，效率提升巨大。


### 📄 文档体验优化

文档的版本控制和编辑体验做了整体优化，文档写作过程中会自动保存内容，并根据文档变化内容自动判定是否保存为一个新版本，配合**Token 自动续期**，写文档也不怕中途掉登录了。

### ⏱️ 会话超时上限

之前很多人反馈在内网使用SmartTable的场景，需要维持长期登录状态。这次把会话超时时间上限调到了 10080 分钟（7 天）。**注意这个不建议调太大**，有安全隐患——别人拿着拦截的 Token 一直能用。

## 五、工程层面：把"看不见的地基"也升级了

### pnpm 迁移完成

前端构建从 npm 全面迁移到了 **pnpm**。包括：

- Docker 镜像构建
- 打包脚本 `build.py`
- 文档说明
- 锁文件 `pnpm-lock.yaml`

对普通用户来说没差别，但使用更加先进的pnpm，开发体验更加友好。

### 数据库迁移用 Alembic

后端的数据库结构变更，改用 **Alembic** 来管理。**支持版本自动升级**——以前升级时手动改表结构那种日子一去不复返了。

## 六、修了哪些 Bug？

这次修的 bug 不少，挨个列：

- **看板拖拽**：修复了拖拽时没用目标分组 ID 的问题、拖拽后分组字段没同步更新的问题
- **表格交互**：修复了**新增一次增加 2 行**的诡异 bug，修复了字段类型转换和默认值问题
- **字段编辑**：修复了字段编辑面板确认后字段管理面板异常
- **附件**：修复了附件字段删除弹窗遮挡、删除失效；修复了点击缩略图时触发单元格选择
- **工作流**：修复了空结果处理和空节点校验；修复了内联 Webhook 拦截；修复了时区获取
- **文档**：修复了文档版本控制和编辑体验的问题
- **会话超时自动续期**：修复了会话超时无法自动续期的问题
- **关联字段**：修复了关联字段缓存不刷新、显示错位的问题
- **公式字段**：修复了部分公式字段函数的问题
- **数字字段**：修复了数字字段的小数位设置不生效的问题。

## 七、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS多维表格、WPS多维表格（金山文档多维表格）。

### 核心特性

- **26 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **43+ 个内置公式函数**：数学、文本、日期、逻辑、统计
- **完整工作流引擎**：支持循环、查找记录、发送邮件、记录时间触发器等节点
- **实时协作**：多人同时编辑
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
